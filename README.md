# 🌿 موقع أوراق الخضرة — تنسيق حدائق

موقع تعريفي احترافي لشركة تنسيق حدائق، جاهز للرفع على **GitHub Pages** مجانًا.

## 📁 محتويات المشروع
| الملف | الوصف |
|---|---|
| `index.html` | الموقع الرئيسي (HTML + CSS + JS في ملف واحد) |
| `sitemap.xml` | خريطة الموقع لجوجل |
| `robots.txt` | ملف إرشادات محركات البحث |

## 🚀 طريقة الرفع (بدون برامج، كلها من المتصفح)
1. ادخل على **github.com** وسجّل (أو اعمل إنشاء حساب مجاني)
2. اضغط **New repository** وسمّيه مثلًا `garden-site` (اتركه Public) واعمل **Create**
3. اضغط **Add file → Upload files**
4. اسحب الملفات دي كلها ناحية الشاشة: `index.html` + `sitemap.xml` + `robots.txt`
5. اضغط **Commit changes**
6. اذهب إلى **Settings → Pages**
7. تحت **Branch** اختر `main` و `/ (root)` ثم اضغط **Save**
8. انتظر دقيقة أو دقيقتين، ورابط موقعك هيبقى:
   `https://USERNAME.github.io/garden-site/`

## ⚠️ مهم قبل الرفع
استبدل في ملفي `sitemap.xml` و `robots.txt`:
- `USERNAME` ← اسم مستخدمك في GitHub
- `REPO-NAME` ← اسم المستودع (لو سمّيته `garden-site`)
